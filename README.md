I'm a full-stack builder in Nairobi. I like products that solve a real local problem, like paying, saving, storing grain or getting to work, and I care as much about the systems that get them used as about the code. I'm the Director of **[Daelus](https://www.daelus.co.ke)**, a small software studio: *Websites show. Systems run.*
